## 一句话判断

这个项目没有原地打转。它已经完成了从数据工程、模型微调、坐标纠错到可复用 ISM 工作流的真实收敛，并得到了一批可复核的模型敏感区域；但科学结论仍停留在“候选发现和方法校准”阶段。当前最危险的 AI 偏航，是把基础设施的成熟、报告的完整和分数的精细，误当成生物学问题已经被回答。

项目的主问题不应继续表述为“怎样设计一个更好的 ISM 分数”，而应表述为：

> 在明确的 mm10 转录本和链方向下，对 Saijou 四类细胞聚合 RNA 轨道微调后的 AlphaGenome 和 Borzoi 进行匹配的局部序列扰动，能否稳定定位改变目标细胞 RNA 预测的序列区段；这些效应中，哪些是跨模型复现、由原生 motif 破坏支持、相对其他细胞优先，并且相对于原始模型的一般调控敏感性提供了新增信息，从而值得进入湿实验验证？

这里的目标是**筛选值得验证的候选区段**，不是仅凭模型证明调控因果、具体 TF 身份或肝纤维化机制。

老板还提出：阈值在已知 TF 正对照上校准后，再应用到其他基因，并请 Saijou 判断哪些结果在生物学上有用。这实际上定义了两段验证：

1. **方法学验证：**在预注册的已知位点和中性区段上衡量召回与误报。
2. **领域专家验证：**对盲选出的新候选，由 Saijou 判断是否值得进入后续生物学实验。

AI 容易把第二段专家反馈写成“ground truth”，也容易把第一段的控制召回写成“新机制验证”。二者都不对：前者是候选优先级判断，后者是方法校准。

## 2. 更精确的科学问题

### 2.1 研究对象

- 物种与组装：小鼠 `mm10`。
- 数据来源：Saijou 肝纤维化/恢复的四时间点单细胞项目。
- 当前模型实际输入：聚合到 HSC、macrophage、LSEC、cholangiocyte 的四条 10x 3′ RNA 轨道；时间点没有保留为独立模型输出。
- 当前主范围：九个预先给定基因，HSC 为首要解释对象；`Mdk` 为深度案例。
- 坐标权威：老板提供的九个转录本 PDF，经 mm10 GTF 核对后固化在转录本配置表中。

### 2.2 干预与观测量

- 干预：以转录方向报告的 TSS `-1500..+1500 bp` 范围，10-bp 单核苷酸组成保持 shuffle，2-bp 步长，每个中心三个替换序列。
- 模型：AlphaGenome-FT epoch 19 与 Borzoi-FT epoch 39；必要时在相同 manifest 上比较 original model。
- 主效应量：固定 3′/TES RNA readout 上的 signed `log2(mutant/reference)`。
- 注意：signed log2FC 给出预测变化方向和大小；它不是显著性、可靠性或区域重要性本身。
- 原始模型多轨道：只能提供一般转录/染色质上下文；老板已明确提醒这些轨道应假定并非同一细胞类型，因此不能作为 Saijou HSC 的匹配验证数据。

### 2.3 真正需要估计的量

对每个候选区段，需要分开回答五个问题：

| 证据级别 | 可回答的问题 | 当前不能偷换成什么 |
|---|---|---|
| 1. 模型敏感性 | 扰动是否改变指定 readout 的预测 | 统计显著性 |
| 2. 稳健性 | 位置、方向和排序能否跨替换、跨模型复现 | 生物学因果 |
| 3. 序列归因 | 原生 motif 是否被稳定破坏，是否排除剪接等结构性解释 | 具体 TF 已结合 |
| 4. 状态优先性 | HSC 效应是否稳定强于另外三类细胞，且不是低信号比值放大 | HSC 特异性 |
| 5. 实验优先级 | 综合正对照校准、原始模型背景和正交数据后是否值得验证 | 已验证的调控元件 |

这个分层是项目当前最需要冻结的“科学接口”。评分函数只是服务于这些问题的工具，不能反过来定义科学问题。

老板提出的 `logFC`、原始表达量、局部极值和基因依赖阈值，并不是四选一：

- `signed log2FC` 描述效应方向与相对大小；
- reference abundance 判断低本底下的 ratio 是否被放大；
- local maxima 与空间聚类把相邻 2-bp centers 变成一个候选区段；
- calibrated threshold 决定这个区段是否进入候选集；
- positive/neutral controls 决定阈值是否有可迁移性。

因此，“重要区域”应定义为一个**经过空间聚类、在相近测量条件下异常、并通过独立控制校准的区段**，而不是一个 log2FC 最大的窗口。

## 3. 哪些地方可能被 AI 带偏

### 3.1 把工程闭环误认成科学闭环

仓库已经有统一 runner、schema、validator、report harness、坐标权威和大量 PDF。这说明结果可重复、错误更容易暴露，但不说明候选区段具有生物学真实性。当前基础设施收敛度明显高于科学结论收敛度。

**纠偏：**每次报告先列“关闭了哪个科学决策”，再列新增文件和图。没有关闭决策的报告只是工作记录。

同样，fine-tuning loss 下降或 ISM 重复稳定，只说明模型内部计算稳定。如果 reference prediction 没有重现实测峰的位置、形状和细胞差异，ISM 解释的是模型依赖性，而不是已建立的样本调控依赖性。

### 3.2 把排序分数误认成证据强度

九基因分数 `>=95` 是经验百分位发现阈值；原始多轨 Method 3 的 `>95` 是基因内前 5% 中心。二者都不是概率、p 值、FDR 或跨基因可比较的效应量。改变聚合、空间平滑、轨道分组和再排名，都能得到看似合理的新高分区段。

**纠偏：**分数只负责提出候选；候选是否可信必须由独立正对照、留出集、跨模型方向和 motif/结构证据判断。

### 3.3 把“HSC 排第一”写成“HSC 特异”

`Mdk +463..+475` 在两个微调模型中 HSC 均排第一，但 Borzoi 的 HSC/次高细胞仅约 `1.11×`。这支持“HSC-prioritized”，不支持“严格 HSC-specific”。类似地，原始模型轨道中的弱或混合证据，不能证明微调创造了新的调控元件。

**纠偏：**只有在效应大小、相邻细胞差距、参考信号、跨模型方向和正交数据同时满足预注册标准时，才升级为细胞状态特异性主张。

### 3.4 在小基准上不断优化，造成方法过拟合

最新三基因原始模型探索比较了三种多轨评分。Method 3 在 AlphaGenome 上冻结后迁移到 Borzoi，这是正确方向；但正式同宽窗口召回在两模型中仍为 `1/4`。如果继续根据同四个控制和同三个基因调分数，方法会越来越贴合已知答案，却不一定更通用。

**纠偏：**立即把控制拆成 development 与 holdout；增加预先登记的中性区段。任何新方法只能看 development，最终只在 holdout 评估一次。

### 3.5 从可测问题扩张到宏大机制

`Wnt9b/Sfrp2` 肝纤维化假说很有价值，但当前 `Wnt9b` 的零命中受 LSEC proxy 与 Endo4/vascular EC 不匹配影响，不能写成生物学阴性。类似地，JASPAR family loss 不能升级成某个 TF 的直接结合，更不能直接升级成肝纤维化机制。

当前四个模型 heads 还丢失了时间点，因此也不能直接讨论纤维化发生与恢复过程中的动态调控。

**纠偏：**肝纤维化故事暂时作为候选来源；主线先回答模型能否可靠恢复已知调控，再讨论新机制或时间动态。

## 4. 当前进度：哪些已经完成，哪些仍未完成

### 已经站稳的部分

1. **工程与数据层。** Borzoi/AlphaGenome 微调、mmap 数据读取、共享模型接口、可复用 ISM core 和验证 harness 已形成。
2. **坐标层。** 九个指定转录本、mm10、链方向、TSS 几何和负链报告方式已经显式化；五个早期错误 anchor 已纠正。
3. **九基因基线。** 两个微调模型各有 `770,676` 个有限 feature rows；`13,443` 个可变中心进入分析；score `>=95` 展示 27 个区段，其中 19 个有一致原生 motif loss。
4. **Mdk 深审计。** `+463..+475` 是跨模型 HSC 优先、SP/KLF-family 支持的候选；`+499..+507` 更像一般转录敏感模块。两者角色已被区分。
5. **原始模型探索。** 三基因 Method 3 已先在 AlphaGenome 冻结再迁移 Borzoi；跨模型 score Spearman 为 Mdk `0.680`、Col1a1 `0.879`、Acta2 `0.876`。

### 仍未关闭的科学问题

1. **阈值未校准。** 九基因 score `>=95` 仅召回 `2/7` 控制；90 和 70 分别召回 `4/7`、`5/7`，但没有独立中性集和 FDR。
2. **多轨分数未验证。** 原始模型 Method 3 在 AlphaGenome 与 Borzoi 的正式同宽窗口召回均为 `1/4`；component view 的 `3/4` 只能作为探索性诊断。
3. **上游模型与细胞状态证据不足。** 目前最强结论是 HSC-prioritized，而非 HSC-specific；四类轨道不是生物重复，早期观察到的共同 peak 形状问题也意味着 reference prediction fidelity 仍应作为独立门禁。
4. **疾病时间维度缺失。** 四时间点数据在当前四条 cell-type bigWig 中没有成为独立输出，无法检验纤维化到恢复的动态变化。
5. **实验真值缺失。** motif 仍主要到 family；目前没有 matched perturbation、allelic effect 或 HSC chromatin/occupancy 数据完成最后校准。

因此，项目当前阶段应标记为：

> **基础设施已具备；模型候选发现已完成第一轮；评分与生物学解释正在校准；尚未进入新调控机制的验证阶段。**

## 5. 为什么一直没有收敛：结果不支持收敛，而不是主观拒绝收敛

当前反复更换扰动方式、评分规则、轨道组合和解释框架，主要是对不稳定证据的合理反应。你不是不愿意结束探索，而是已有结果一直不足以支撑一个稳定的正面结论：

- score `>=95` 只召回 `2/7` 九基因正对照；
- 原始模型多轨 Method 3 在 AlphaGenome 和 Borzoi 的正式召回均为 `1/4`；
- `Mdk +463..+475` 虽然在两个模型中 HSC 排第一，但 Borzoi 的 HSC/次高细胞仅约 `1.11×`；
- 模型、readout、阈值和扰动方式变化都会改变部分候选及其排序。

在这种情况下，直接冻结一个“成功发现重要区域”的故事是不科学的。继续检查替代解释、寻找更稳健定义，本身属于正常研究过程，不是原地踏步。

但是，科研收敛不只意味着获得预期的阳性结论。结果长期不稳定时，也应该收敛到一个边界清楚的方法学结论：

> **现有微调模型和 ISM 能发现部分跨模型、motif-backed 的敏感区段，但尚不能可靠、通用地识别重要调控区域，也不足以证明 HSC 特异性或新的肝纤维化机制。**

这不是项目失败，而是当前证据能够支持的最高等级结论。它同时指出了下一步需要增加的不是另一种评分公式，而是独立 holdout、neutral regions、matched HSC 正交数据或湿实验反馈。

从这里开始，继续探索需要满足一个信息增益条件：

> 新实验必须引入独立证据或检验一个可被否定的假设；只在同一批基因和控制上调整评分，不再视为实质性科学推进。

因此，更准确的诊断是：**你此前没有收敛，是因为结果不足以支持阳性收敛；当前需要做的，是先收敛到“现有证据的限制”，再等待新证据重新打开问题。**

## 7. 最终判断

你的研究输入并不浅，也不是被 AI 完全推着走。最强的证据是：你多次纠正了模型和报告中的核心假设——内存机制必须实验验证、左右图坐标必须一致、负链方向必须纠正、老板给出的转录本才是坐标权威、正控制必须是真实位点、score 不能代替 log2FC、HSC 排第一不等于 HSC 特异、以及新实验不能复制整套工作流。

真正的问题是，这些判断经常在 AI 已经生成大量代码、分析和报告之后才被固化。结果是**你的科学判断存在，但它进入系统得太晚**。AI 的速度把“尚未冻结的疑问”迅速放大为多个实验分支，使你看起来像在发散。

下一阶段的科研能力不再取决于能否多跑一个模型，而取决于能否提前写下：

> 什么观察会让我相信候选值得验证？什么观察会让我否定当前评分？到什么程度必须停止扩展？

只要把这三个判断变成预注册门槛，AI 就会从“任务扩张器”变成“受约束的实验执行器”。这也是本项目从高质量研究工程走向可辩护科学结论的分界线。
